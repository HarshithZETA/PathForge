# PathForge: Fixes That Stay Fixed

Proposal for CyberForge by Harshith P. and Karthik S.

PathForge turns an organisation into a versioned attack graph, finds the
routes to critical assets, ranks the smallest set of fixes by risk removed,
effort and secondary exposure, tests them on parallel graph copies ("twins"),
and flags when an earlier fix becomes incomplete after new findings.
A language model writes explanations only from verified evidence, and a
claim checker drops any sentence that cites nothing.
